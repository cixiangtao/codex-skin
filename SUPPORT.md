# Support

English | [简体中文](SUPPORT.zh-CN.md)

Codex Skin is in maintenance mode. Read the [project status](MAINTENANCE.md) and [full documentation](.github/README.md) before opening an issue.

The project may consider critical security, recovery, and narrowly scoped compatibility fixes. New product features, cross-platform ports, theme protocols, and marketplace work are out of scope. For actively developed theme features, use the [Codex Dream Skin repository](https://github.com/Fei-Away/Codex-Dream-Skin) and report its bugs there rather than here.

For a maintenance-scope Codex Skin bug, use the GitHub bug form and include the desktop release tag or npm CLI version, macOS version, chip architecture, Codex desktop version, minimal reproduction, expected behavior, actual behavior, and sanitized logs or screenshots.

The supported product scope is currently Apple Silicon macOS. Intel Mac, Windows, and Linux are not promised runtime targets.

Report suspected vulnerabilities or token exposure privately through [Security](SECURITY.md). Codex Skin is unofficial and unaffiliated with OpenAI; use official support for Codex product or account issues.
