# Support

English | [简体中文](SUPPORT.zh-CN.md)

Read the [full documentation](.github/README.md), especially the requirements, installation path, startup mechanism, and security boundary.

For bugs and compatibility issues, use the GitHub bug form and include the desktop release tag or npm CLI version, macOS version, chip architecture, Codex desktop version, minimal reproduction, expected behavior, actual behavior, and sanitized logs or screenshots.

The supported product scope is currently Apple Silicon macOS. Intel Mac, Windows, and Linux are not promised runtime targets.

Report suspected vulnerabilities or token exposure privately through [Security](SECURITY.md). Codex Skin is unofficial and unaffiliated with OpenAI; use official support for Codex product or account issues.
